# เนื้อเรื่องและ Storyboard เกม Eternal Clash

## 📜 แก่นเรื่อง (Storyline)
**"ยุคแห่งความโกลาหล เมื่อบัลลังก์ไร้ผู้ครอบครอง"**
แผ่นดินที่เคยสงบสุขต้องลุกเป็นไฟ เมื่อจักรพรรดิองค์สุดท้ายสิ้นพระชนม์โดยไร้รัชทายาท แว่นแคว้นต่างๆ แตกกระจายเป็นก๊กเป็นเหล่า เหล่าขุนศึกและกุนซือในตำนานทั้ง 7 (โจโฉ, เล่าปี่, ซุนกวน, ขงเบ้ง, จิวยี่, จูล่ง, ลิโป้) ต่างตั้งตนเป็นใหญ่และรวบรวมกำลังพล เป้าหมายมีเพียงหนึ่งเดียวคือการพิชิตแว่นแคว้นอื่น ครองความเป็นใหญ่ และรวบรวมแผ่นดินให้เป็นปึกแผ่นอีกครั้ง

แต่ศัตรูไม่ได้มีเพียงแค่มนุษย์... ฤดูกาลที่โหดร้าย ภัยธรรมชาติที่คาดเดาไม่ได้ (หลุมยุบ, พายุหิมะ, น้ำท่วม, กบฏชาวบ้าน) จะเป็นตัวตัดสินว่าใครคือผู้ปกครองที่แท้จริง ผู้ที่วางแผนทรัพยากรได้ดีที่สุดและอ่านเกมของศัตรูออกเท่านั้น ที่จะได้เป็นผู้รอดชีวิตคนสุดท้าย (Last Man Standing)

---

## 🎬 Storyboard (ฉากเปิดเกม / Trailer)

### **Scene 1: ปฐมบทแห่งความวุ่นวาย**
- **Visuals (ภาพ):** ภาพมุมกว้าง (Bird-eye view) ของเมืองหลวงที่กำลังถูกไฟเผาผลาญ ท้องฟ้ามืดครึ้ม ควันไฟพวยพุ่ง กล้องค่อยๆ แพนลงมาที่แผนที่ทวีปที่ถูกขีดเส้นแบ่งออกเป็นหลายส่วน
- **Audio (เสียง):** เสียงดนตรีพื้นหลังแบบอลังการ (Epic Orchestral) ผสมเสียงไฟปะทุและเสียงม้าร้อง
- **Text/Voiceover:** *"เมื่อบัลลังก์ว่างเปล่า... ความภักดีจึงกลายเป็นเพียงฝุ่นผง"*

### **Scene 2: การเปิดตัวของเหล่าตำนาน (Draft Phase)**
- **Visuals (ภาพ):** ตัดสลับภาพ (Fast Cuts) ของเหล่าแม่ทัพ:
  - **ลิโป้** ควงง้าวกรีดร้องกลางสมรภูมิ
  - **ขงเบ้ง** นั่งดีดพิณอยู่บนหอคอยพร้อมสายลมพัดผ่าน
  - **โจโฉ** ยืนจ้องมองแผนที่ทหารด้วยสายตาคมกริบ
  ภาพตัดมาที่ UI การเลือกแม่ทัพ (Draft Screen) ที่ผู้เล่นกำลังแย่งกันเลือกตัวละคร
- **Audio (เสียง):** จังหวะดนตรีเร็วขึ้น เสียงกลองรบดุดัน
- **Text/Voiceover:** *"จงเลือกผู้นำของคุณ... เพราะพวกเขาคือชะตากรรมของเมือง"*

### **Scene 3: การดิ้นรนและการบริหาร (Gameplay - Economy)**
- **Visuals (ภาพ):** 
  - ภาพแอนิเมชันชาวบ้านกำลังเกี่ยวข้าวในฤดูร้อน (ทำฟาร์ม)
  - ตามมาด้วยภาพทหารกำลังฝึกซ้อมดาบ (เกณฑ์ทหาร)
  - ทันใดนั้น ฤดูกาลเปลี่ยนเป็นฤดูหนาว พายุหิมะโหมกระหน่ำ (Event: พายุหิมะปกคลุม) ชาวบ้านล้มตาย เสบียงลดฮวบ โชว์ให้เห็นถึงความกดดันในการเอาชีวิตรอด
- **Audio (เสียง):** เสียงลมพายุพัดแรง เสียงชาวบ้านโอดครวญ ดนตรีบีบคั้นอารมณ์
- **Text/Voiceover:** *"ธรรมชาติไม่เคยปรานีใคร... เตรียมเสบียงและกำลังพลให้พร้อม"*

### **Scene 4: สงครามจิตวิทยา (Gameplay - Combat)**
- **Visuals (ภาพ):** ผู้เล่นกดปุ่ม "โจมตี!" กองทัพจุดสีแดงเคลี่อนที่ข้ามแผนที่ในยามค่ำคืน แต่ระหว่างทางเจอ "ฟ้าผ่า" กองทัพเสียหาย! จากนั้นตัดไปที่เมืองเป้าหมาย ทหารสองฝั่งปะทะกัน ตัวเลขทหารลดลงอย่างรวดเร็ว โชว์หน้าต่าง Log การต่อสู้
- **Audio (เสียง):** เสียงดาบปะทะกัน เสียงฟ้าร้อง เสียงตะโกนรบ
- **Text/Voiceover:** *"การตัดสินใจเพียงครั้งเดียว... อาจหมายถึงจุดจบ"*

### **Scene 5: ผู้รอดชีวิตคนสุดท้าย (Victory)**
- **Visuals (ภาพ):** หน้าจอถูกพัดผ่านด้วยก้อนเมฆ (Cloud Transition) และเปิดมาพบกับซากปรักหักพังของเมืองศัตรู ธงของเมืองผู้ชนะถูกปักลงกลางสมรภูมิ ตัดเข้าสู่ฉาก **Win Animation** ของแม่ทัพผู้ชนะ แผง UI ผู้ชนะเด้งขึ้นมากลางจอ
- **Audio (เสียง):** ดนตรีบรรเลงเพลงแห่งชัยชนะ (Triumphant Brass) 
- **Text/Voiceover:** *"แผ่นดินรวมเป็นหนึ่ง... ผู้ชนะมีเพียงผู้เดียว!"*
- **End Title:** โลโก้ **"ETERNAL CLASH"** ปรากฏขึ้นพร้อมปุ่ม เริ่มเกม
